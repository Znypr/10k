# Social metric automation

`assets/stats.json` is generated by `scripts/update-stats.mjs` and must not be edited manually.

The GitHub Action `.github/workflows/update-social-stats.yml` runs every six hours, on manual dispatch, and after the automation files are first merged into `main`.

## Data sources

The collector reads public profile data for YouTube, TikTok, Twitch, Instagram, Facebook, Snapchat and X. If a platform temporarily blocks a request or does not publish a count, the previous valid value is retained and marked as stale instead of replacing it with an invented number.

YouTube publicly rounds subscriber counts for larger channels. In that case the website displays the current platform-reported value rather than pretending a hidden exact count is available. Snapchat counts also depend on whether the public profile exposes its subscriber count.

## Optional official API secrets

The scraper works without repository secrets. These optional Actions secrets improve reliability where official APIs are available:

- `YOUTUBE_API_KEY`
- `TWITCH_CLIENT_ID`
- `TWITCH_CLIENT_SECRET`
- `META_ACCESS_TOKEN`

The website itself never receives these secrets. They are used only inside GitHub Actions to regenerate the static JSON file.
